================================================================================
QUICK FIX - Most Common Issues
================================================================================

1. Server stopped - Just restart:
    cd /var/www/mycrip-8002
    php artisan serve --host=0.0.0.0 --port=8002 &

2. Port in use - Kill existing:
    pkill -f "artisan serve"
    cd /var/www/mycrip-8002
    php artisan serve --host=0.0.0.0 --port=8002 &

3. Permissions issue:
    chmod -R 775 /var/www/mycrip-8002/storage
    chmod -R 775 /var/www/mycrip-8002/bootstrap/cache
